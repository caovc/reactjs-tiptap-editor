# SAP 编辑演示：Reference lock & decision ledger

## 研究与边界

- 任务：在既有 ReUI 编辑器上直接构建中文临床统计分析计划工作台，不是重新品牌设计、营销页或 SAP ERP。
- Refero MCP 的 styles-first 三角检索（精确灰白企业生产力 / 科学文档 / Notion 文档）均返回 `NO_SUBSCRIPTION`。未取得真实 styles/screens，不能声称完成了参考图研究；不绕过订阅、不购买服务。依照既定 direct-build 要求继续，以用户的 Word 式文档约束、现有官方 ReUI v1 控件，以及 Refero 随附 typography / craft-details / visual-workflow 为依据。此限制保留在交付报告。
- 基线仓库：743e028；开始时工作树干净、HEAD 与 origin/main 一致。

## Reference lock（实现前锁定）

**主方向：精密的文档工作台。** 清晰三栏、紧凑功能区、连续白纸；操作界面中性无衬线，正文采用适合中文长文的衬线字族。不是 Word 品牌克隆。

| 角色 | 锁定规则                                                                         | 依据                                                                 |
| ---- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 顶部 | 约 52px 文件栏 + 36px 标签 + 紧凑分组功能区；主动作仅导出                        | 用户 Word 约束，现有 ReUI Tabs/Button                                |
| 主体 | 左 224px 活目录 / 中央可滚动 A4 连续纸张 / 右 288px 方案助手                     | 文档阅读与导航任务优先                                               |
| 颜色 | ReUI light/blue 语义主题；白面板、浅灰工作区，蓝仅选中/主动作；琥珀仅批注/待核对 | 保留现有 design system，禁止任意改 primitive token 含义              |
| 排版 | 工具 12–14px，正文 14px/1.9，标题 20/18/16px；正文实际可编辑，不用图代替         | Refero 随附 typography：工作工具中性、清晰；内容型产品可另设正文衬线 |
| 表面 | 细边框分组，仅纸张轻微阴影；不用大圆角卡片或装饰渐变                             | 高密度专业工具约束                                                   |
| 媒体 | 无图片需求。Lucide 现有图标只承担操作语义，不生成品牌/装饰图                     | code-native 编辑器界面                                               |
| 窄屏 | 左右面板可切换隐藏；功能区横向滚动，纸张可横向滚动；所有任务仍可进入             | Craft：避免溢出和无标签图标按钮                                      |
| 焦点 | ReUI primitives、可见键盘焦点、真实按钮/标签、对话框标题/说明                    | Refero craft-details                                                 |

### 明确拒绝

- 不复制 Word 商标/官方身份；不伪装协作、追踪修订、电子签名或 GxP 合规。
- 不用背景横线伪装分页；采用连续 A4 宽度纸张，浏览器打印才真实分页，不承诺屏幕页码。
- 不引入其他 UI 套件；只复用已验证来源的 ReUI v1 primitives，自定义 ribbon/field/outline/assistant 为其组合。
- 不把结构检查称为统计方法验证；无真实病人数据、临床推荐或服务端上传。

## Decision ledger

| 决策                                   | 理由                                                                 | 验证方式                             |
| -------------------------------------- | -------------------------------------------------------------------- | ------------------------------------ |
| Vite 多页面 `/sap/`                    | GitHub Pages 子目录下可直接打开，无 SPA fallback，原 playground 不变 | 双入口构建、HTTP、线上浏览器测试     |
| 独立 SAP schema/插件，复用已发布库扩展 | 保留库公开 API、隔离领域逻辑                                         | 原类型/构建/浏览器回归               |
| 标题稳定 ID + 自动编号                 | 同一来源驱动正文编号、活目录与导航；编辑标题不失联                   | 修改标题、目录跳转、JSON 恢复        |
| 文本 mark 批注                         | 随 ProseMirror 编辑映射，不保存脆弱的绝对位置；删除锚点明确提示      | 锚定、编辑、解决/重开、刷新          |
| Zod + ProseMirror schema + DOMPurify   | 不信任导入，白名单节点/样式与体积深度限制；HTML 不执行脚本/加载外链  | 非法 JSON / XSS HTML / 往返导入      |
| 本地草稿 / 明确导出                    | 不需要账户；失败和多标签冲突不能静默覆盖                             | 刷新恢复、错误提示、结构化 JSON 导出 |
